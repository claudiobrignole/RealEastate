# Custom Agent Rules for UnitLeads

## 1. Focused Responses and Turn-Specific Diagnostics
- Always respond **only** to the active prompt and files modified in the current turn.
- Do **not** list previous accomplishments, past phases, or the entire project history in the final status summaries unless specifically requested.
- Keep the summary to a concise, scannable overview of the precise changes made in the latest turn.
- Acknowledge the overall roadmap memory silently or keep it in the background without reiterating it.
